# 링스온 디오라마 편집 가이드

편집할 파일은 **index.html** 하나입니다. 메모장, VS Code, 또는 GitHub 웹(파일 열기 → 연필 아이콘)에서 고칠 수 있어요.
Ctrl+F로 바꾸고 싶은 **글자를 그대로 검색**하는 게 가장 빠릅니다.

## 1. 오른쪽 설명 패널 글자 → `facilities()` 부분 ([B] 표시)
| 항목 | 화면 위치 |
|---|---|
| name | 시설 이름 (큰 제목, 왼쪽 시설 라벨) |
| floor · tag | 제목 위 파란 작은 글씨 |
| desc | 제목 아래 회색 설명 |
| label | STEP 버튼 이름 |
| title · body | 아래 회색 박스 제목·본문 |
| push | 오른쪽 "입주민 앱 알림" 문구 |

- 작은따옴표 `' '` 안의 글자만 바꾸세요. 따옴표·쉼표·괄호를 지우면 화면이 안 나옵니다.
- 글자 안에 작은따옴표(')를 넣으려면 `\'` 로 쓰세요.
- `\n` 은 줄바꿈이 되지 않고 띄어쓰기처럼 보입니다.
- `scene` 값은 바꾸지 마세요(사진 연결 이름).

## 2. 사진 위 말풍선 문구 → `<template>` 안 ([A] 표시)
`<text ...>스피드게이트 통과</text>` 처럼 `<text>` 태그 사이 글자를 바꾸면 됩니다.
글자가 길어지면 뒤 배경 상자가 짧아 보일 수 있어요. 바로 앞 `<rect ... width="190"` 의 width 숫자를 키우고, `<text x="115.0"` 의 x를 (20 + width/2)로 맞추세요.

## 5. 사진 바꾸기
`images` 폴더에서 **같은 파일 이름**으로 덮어쓰면 끝입니다. (가로:세로 16:9 권장)
| 파일 | 장면 |
|---|---|
| gym1~3 | 피트니스 STEP 1~3 |
| gx1~3 | GX룸 |
| golf1~3 | 실내 골프연습장 |
| cafe1~3 | 카페 라운지 |
| sauna2, sauna1, sauna3, sauna4 | 사우나 STEP 1~4 (순서 주의) |
| study1, study3 | 스터디카페 STEP 1~2 |
| kids1~3 | 키즈카페 |
| guest1~4 | 게스트하우스 |
| floor_all, floor_ph, floor_60f, floor_50f, floor_45f, floor_1f | 왼쪽 3D 디오라마 (PNG, 900×1000, 배경 투명) |

## 6. 올리기
고친 파일을 GitHub 저장소에 덮어 올리면 1~2분 뒤 사이트와 가비아 홈페이지에 반영됩니다.
반영이 안 보이면 브라우저에서 Ctrl+F5(강력 새로고침).

## 문제가 생기면
화면이 하얗게 나오면 대부분 따옴표·쉼표가 빠진 경우입니다. 마지막으로 고친 곳을 되돌려 보세요.
