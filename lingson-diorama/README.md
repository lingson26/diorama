# 링스온 커뮤니티 디오라마

층별로 잘라 본 링스온 커뮤니티 미니어처 웹 시안입니다.

## GitHub Pages로 공개하기
1. 이 폴더의 파일 전체(index.html, images 폴더, .nojekyll)를 저장소 맨 위에 올립니다.
2. Settings → Pages → Branch: `main` / `(root)` → Save
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 에서 열립니다.

## 홈페이지(가비아 등)에 넣기
`embed.html` 의 코드에서 주소를 바꿔 붙여넣으세요.
